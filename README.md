# Uzayr Qureshi — Portfolio

[![CI](https://github.com/mr2buzi/Uzayr/actions/workflows/ci.yml/badge.svg)](https://github.com/mr2buzi/Uzayr/actions/workflows/ci.yml)

Source for [uzayr.netlify.app](https://uzayr.netlify.app/), a React/TypeScript portfolio presenting selected systems, backend, AI and product-engineering work.

## Stack

- React and TypeScript
- Vite
- Three.js
- Responsive CSS
- Netlify deployment

## Run locally

```bash
npm install
npm run dev
```

Verify a production build:

```bash
npm run build
```

Project and experience content is maintained in `src/content/siteData.ts`. The downloadable text CV is maintained in `public/Uzayr-Qureshi-CV.txt`.
